# Legacy Scripts

Deprecated scripts and manual sync helpers that are no longer part of the active CI/CD or testing workflows.

- `sync_cline_skills.sh` — legacy shell script for manually pushing skills to `~/.cline/skills/` (superseded by `litellm-marketplace install`).
- `sync_opencode_skills.sh` — legacy shell script for manually pushing skills to `~/.config/opencode/skills/` (superseded by `litellm-marketplace install`).

These are kept for reference only. Please use `litellm-marketplace` and `litellm-mcp` CLIs for current operations.
